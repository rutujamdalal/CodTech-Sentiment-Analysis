# 🐦 Twitter Airline Sentiment Analysis
**CodTech IT Solutions Internship — Project 2**

## 📌 Objective
Analyze sentiment of 14,640 US airline tweets using NLP techniques to identify customer pain points and satisfaction levels across 6 major airlines.

## 🛠️ Tools & Technologies
- Python, Pandas, NumPy
- NLTK (VADER Sentiment Analyzer)
- Matplotlib, Seaborn, WordCloud
- Google Colab

## 📊 Key Findings
- 62.7% of tweets were negative
- United Airlines received the highest complaint volume
- US Airways had the worst average sentiment score
- Customer Service Issue was the #1 complaint (32% of negatives)
- Virgin America had the best overall sentiment score

## 📁 Project Structure
- `sentiment_analysis.ipynb` — Main notebook with full analysis
- `Tweets.csv` — Dataset (14,640 tweets)
- `chart1_sentiment_distribution.png` — Overall sentiment breakdown

- `chart5_vader_scores.png` — VADER score comparison
